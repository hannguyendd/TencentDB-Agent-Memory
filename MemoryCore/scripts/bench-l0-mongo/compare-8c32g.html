5. Conclusions

  • w:1 verified. 100M docs in 32 min, 51,631 docs/s, 0 errors, 0 stalls, BM25 READY.
  • The root cause of w:majority stalls is replication lag. 3 flow-control triggers = 3 complete stalls; switching to w:1 eliminates the problem.
  • The query bottleneck is the network. After subtracting RTT, most queries take <10ms on the server; running in the same DC or raising concurrency would help substantially.
  • Production advice. w:1 gives up cross-node durability guarantees; if the workload needs majority safety, throttle the write rate or improve secondary replication capacity.
